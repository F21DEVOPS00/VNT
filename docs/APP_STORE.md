# App Store 출시 준비

현재 소스는 개발 첫 버전입니다. 출시 완료나 심사 통과를 의미하지 않습니다.

## 계정 및 앱 식별
- Apple Developer 계정의 Membership details에서 멤버십 상태, 만료일, 팀을 확인합니다.
- Expo 계정과 EAS 프로젝트를 연결합니다.
- 최종 앱 이름, 고유 bundle identifier, 지원 이메일, 개인정보처리방침 URL을 확정합니다.
- App Store Connect에 앱을 등록하고 계약·세금·은행 정보는 계정 소유자가 직접 확인합니다.

## 실제 서비스 연결
- 운영 HTTPS 서버, OpenAI 프로젝트/API 예산, 발신 도메인이 인증된 SMTP 제공자.
- Supabase 사용자 가입·이메일 확인·로그인·토큰 갱신·비밀번호 재설정·계정 삭제.
- 사용자별 과금/사용량 정책. 공용 API 키를 앱에 포함하지 않습니다.
- 파일 저장소의 백업/보존/삭제 정책과 영속 작업 큐. 앱이 닫혀도 서버가 처리하고 이메일을 보내도록 전환합니다.
- SMTP 메일 도착·스팸 분류·반송, 한국어 제목과 본문, 1~10명 수신자 확인.
- 신규 사용자에게 회사 이메일을 기본 수신자로 넣지 않습니다.

## 실제 iPhone 필수 검사
- 마이크 허용/거부, 화면 잠금, 앱 전환, 전화 수신, Bluetooth 오디오 연결 해제.
- 1분 / 30분 / 긴 회의, 일시정지/재개, 저장공간 부족.
- 네트워크 해제·복구와 업로드 중 앱 종료. 녹음 원본 보존.
- 한국어/영어 혼합 음성, 침묵, 소음, 숫자·금액·날짜, 임의 할 일 생성 여부.
- 이메일 중복 전송 방지와 불확실한 발송 상태의 수동 재전송.
- 로그인 만료와 재로그인, 회원 탈퇴와 기기 데이터 삭제.
- VoiceOver, 큰 글씨, 작은 화면, 다크모드 지원 여부.

## 심사 자료
- 검토된 개인정보처리방침 및 지원 페이지. 실제 수집/전송 정보와 App Privacy 설문을 일치시킵니다.
- 녹음/AI 외부 전송/메일 발송 안내와 사용자의 선택.
- 실제 기기로 촬영한 스크린샷, 앱 설명, 심사용 테스트 계정과 서버 가동.
- 계정 생성이 있으면 앱 내 계정 삭제 경로 제공.
- 디지털 AI 유료 기능 판매 시 Apple 결제 정책 확인 후 구현.
- TestFlight 배포 → 실제 사용자 테스트 → App Review 제출.

Apple 계정 로그인과 유료 갱신/계약 승인은 계정 소유자가 진행합니다.
