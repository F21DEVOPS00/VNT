# 개인정보 안내 초안 — 공개 전 운영 정보 입력·검토 필요

운영자/문의처, 시행일, 서버 위치, 보존 기간, 위탁·국외 이전 등 적용 사항은 운영 환경에 맞게 확정해야 합니다. 이 초안은 법률 검토를 대체하지 않습니다.

## 기기에 저장하는 정보
녹음 파일, 회의 제목, 녹취 텍스트, 요약, 결정 사항, 할 일, 개인 메모, 수신 이메일 설정을 앱 저장소에 보관합니다. 로그인 토큰은 iOS 보안 저장소에 보관합니다. 기기 백업 정책에 따라 앱 데이터가 백업될 수 있습니다.

## 외부 처리
사용자가 AI 처리를 시작하거나 녹음 종료 후 자동 흐름을 사용하면 녹음은 앱 서버와 OpenAI에 전송되어 받아쓰기됩니다. 녹취 텍스트는 요약/할 일 추출을 위해 OpenAI로 전송됩니다. 앱 서버는 업로드 임시 파일을 요청 처리 후 삭제하지만, 외부 제공자의 보존 정책은 별도로 적용됩니다.

이메일 발송 시 사용자가 지정한 수신자에게 회의록을 전송하고 SMTP 제공자를 통해 처리합니다. 수신자는 BCC로 전달합니다. 앱 서버에는 사용자 ID와 전송 시도 ID·시각·상태만 저장하고, 회의록 내용을 전송 로그에 저장하지 않습니다. 현재 소스는 로그 보존 기간 자동 삭제가 구현되지 않았으므로 출시 전 정책과 삭제 작업이 필요합니다.

## 사용자 선택
수신자 추가·제거, 자동 이메일 해제, 녹음·회의록 삭제, 로그인 해제와 계정 삭제를 제공해야 합니다. 이미 수신자의 메일함으로 전달된 회의록은 앱에서 회수할 수 없습니다.

## 출시 전 확정
운영자 연락처, 인증·AI·이메일 제공자 목록 및 처리 지역, 실제 보존 기간, 계정 삭제 시 서버 기록 처리, 보안·문의·권리 행사 절차를 확정하고 앱의 설명과 실제 동작을 일치시킵니다.
